# Sobre Mim

Página pessoal simples de apresentação ("about me"), construída para fixar conceitos fundamentais de HTML semântico e CSS.

## 🎯 Sobre o projeto

Projeto iniciado exercício de fundamentos web. O objetivo era praticar:

- Estrutura semântica com `section` e `article`
- Listas ordenadas e não ordenadas
- Reset CSS e estilização de layout
- Manipulação de eventos com `addEventListener`
- Organização de página em cards com Flexbox

## 🛠️ Tecnologias

- HTML5 (semântico)
- CSS3 (Flexbox, transições, box-shadow)
- JavaScript (vanilla, manipulação de DOM)

## 📁 Estrutura

```
aboutMe/
├── assets/
│   ├── imgs/
│   │   └── profile.jpg
│   ├── js/
│   │   └── index.js
│   └── styles/
│       └── main.css
├── index.html
└── README.md
```

## ✨ Funcionalidades

- Layout em cards independentes (header, resumo, habilidades, projetos, experiência, educação, contato)
- Efeito hover nos elementos interativos
- Botão com feedback visual ao clique
- Design responsivo com Flexbox
